# Plum 0.1.11

- Tightened access to Plum's local terminal and status sockets, workspace files, Git operations, Orca import, and update downloads.
- New agent tabs use their own permission settings, and automatic workspace trust is off by default. Existing permissive choices are reset once on upgrade.
- Running 0.1.10 terminals remain attached through the update; new tabs use the hardened terminal host. Existing terminals remain on the old host until they finish.

Install: `brew install --cask yeshyungseok/tap/plum`, or download the ZIP below. Earlier versions can use Plum → Check for Updates…

---

- Plum의 로컬 터미널과 상태 소켓, 워크스페이스 파일, Git 작업, Orca 가져오기, 업데이트 다운로드의 접근 경계를 강화했습니다.
- 새 에이전트 탭은 각 에이전트의 권한 설정을 따르고, 워크스페이스 자동 신뢰는 기본으로 꺼집니다. 이전의 허용 범위가 큰 설정은 업데이트 때 한 번 초기화됩니다.
- 실행 중인 0.1.10 터미널은 업데이트 뒤에도 연결됩니다. 새 탭은 보안 보강된 터미널 호스트를 사용하며, 기존 터미널은 종료될 때까지 이전 호스트에서 실행됩니다.

설치: `brew install --cask yeshyungseok/tap/plum`, 또는 아래 ZIP을 다운로드하세요. 이전 버전은 Plum → 업데이트 확인…에서 설치할 수 있습니다.
