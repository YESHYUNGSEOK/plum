# Plum 0.1.19

- Hardened terminal host identity checks, local status socket reads, workspace and worktree removal, Orca import, update downloads, and project icon decoding.
- Preserved existing agent configuration entries and hook groups when editing permissions and hooks.
- Prevented concurrent app instances from overwriting workspace state. An unreadable state file now stops startup instead of being replaced.
- Updates are deferred when running terminals cannot be restored by the new app.
- A Claude tab left with background work after its turn shows as monitoring again: the terminal's own state signal no longer overrides what the hooks report.
- The archive and delete questions tell work from ignored files: "uncommitted changes" lists changed and new files only, ignored files have a section of their own with what an install or build makes again (`node_modules`, `.next`) folded to a count, and "discard changes" is said only when there are changes.

The app checks for updates daily and offers installation. Applying an update restarts the app. Existing terminal sessions must be checked for compatibility before installation.
